InroScan · Prueba OAuth

Valida que el navegador pueda escribir en Drive y Sheets con la cuenta de quien entra, sin servidor. Responde la duda abierta: si drive.file alcanza para una carpeta preexistente, o hace falta Picker.

1 Configuración

Se guardan solo en este navegador (localStorage). Ninguno es secreto: el Client ID y la API Key van visibles en cualquier app estática. Lo que protege de verdad es a quién le compartiste la carpeta y la hoja.

2 Entrar con Google

Pide permiso de drive.file y spreadsheets. La app actúa como la persona que entra, no como una cuenta de servicio.

3 Las pruebas

2A — Subir un archivo a la carpeta usando su ID directamente. Es el camino cómodo: si funciona, no hace falta Picker.

2B — Si 2A falla con 404, elegir la carpeta con Picker y reintentar. Un 404 acá significa «no autorizado», no «no existe».

4 — Crear una carpeta en «Mi unidad» y volver a encontrarla al listar. Es lo que sostiene el modo rendidor: si el listado no la devuelve, cada sesión crearía una carpeta nueva y se duplicarían.

4 Vaciar el registro

Borra las filas de datos de Registro y Consolidados, dejando los encabezados. Es para iterar: se reprocesa el mismo PDF hasta que la lectura salga bien, y entre corrida y corrida conviene partir de cero.

No se puede deshacer, y afecta a la hoja que use todo el equipo. Para confirmar, escribe VACIAR.
